# System Architecture — Non-Technical Explanation

> A plain-language overview for readers without a technical background.

---

## 🧠 AI Technologies — In Plain Words

Imagine our AI as **one smart bank employee**
with many skills combined. Each technology is one of their abilities.

| Technology | Plain-Language Explanation |
|---|---|
| **LLM (Function Calling / Tool Use)** | The brain that understands human language |
| **RAG (Retrieval-Augmented Generation)** | Ability to look up real account data — not guess |
| **DAG-based Task Planner** | Plans tasks in the correct order, like a checklist |
| **Prompt Injection Defense** | Immunity against attempts to trick the AI |
| **Sandboxed Code Execution** | A safe cage where AI-generated code runs |
| **Multi-Factor Authentication (MFA)** | Extra identity checks for risky actions |

**In short:** Our AI has a brain + accurate memory + planning + immunity + a safe cage + identity verification.
