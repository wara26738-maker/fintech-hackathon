## Overview

Our project introduces an AI-powered banking agent integrated into an existing banking app to make financial management smarter, more accessible, and personalized. It helps users improve financial literacy, manage spending, and make informed decisions through one conversational interface.

## Features

The agent offers six features:

| Feature | Description |
| :--- | :--- |
| **Smart Transfers** | For payments and bill splitting |
| **AI Bill Analysis and Budgeting** | To track spending and optimize expenses |
| **Smart Investment Planning** | To recommend investments based on users risk tolerance and goals |
| **Smart Card Management** | For card controls and security |
| **Subscription Management** | To identify declining usage and reduce unnecessary expenses |
| **Cross-Scenario Orchestration** | To coordinate multiple banking tasks in one workflow |

## AI Technologies

AI technologies power the system:

| Technology | Purpose |
| :--- | :--- |
| **Large Language Models (LLMs) with Function Calling** | To understand requests and execute banking tools |
| **Retrieval-Augmented Generation (RAG)** | To provide data-grounded responses |
| **DAG-Based Task Planner** | To organize complex tasks |
| **Prompt Injection Defense** | To protect against malicious inputs |
| **Sandboxed Code Execution** | To run code safely in a restricted environment |
| **Multi-Factor Authentication (MFA)** | To strengthen verification for high-risk actions |

## Conclusion

By combining personalized insights with secure automation, our solution helps users control spending and achieve their financial goals within one integrated banking experience.
